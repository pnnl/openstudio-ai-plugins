OpenStudio AI installation

Choose the installation path that fits how you work.

Use the terminal for scripted or repository-local setup, or install directly from the standalone desktop clients. Both paths add the same OpenStudio AI plugin.

Terminal-based installation ↓Desktop-client installation ↓
Option 1

Terminal-based installation

Use the marketplace commands when you want repeatable setup from a shell.

Claude Code

Add the marketplace, install the plugin, then reload it in the session.

1

Add the marketplace

claude plugin marketplace add https://github.com/pnnl/openstudio-ai-plugins.git
2

Install the plugin

claude plugin install openstudio-ai@openstudio-ai-local
3

Reload and run setup

/reload-plugins
/openstudio-ai:setup-openstudio-ai
4

Update the plugin

Refresh the marketplace to retrieve the latest OpenStudio AI release, then reload plugins in an active session.

claude plugin marketplace update openstudio-ai-local
/reload-plugins

Codex

Add the marketplace, install the plugin, then run setup in a task.

1

Add the marketplace

codex plugin marketplace add pnnl/openstudio-ai-plugins
2

Install the plugin

codex plugin add openstudio-ai@openstudio-ai-local
3

Run setup in a task

/setup-openstudio-ai
4

Update the plugin

Refresh the marketplace to retrieve the latest OpenStudio AI release, then start a new task or reopen Codex.

codex plugin marketplace upgrade openstudio-ai-local

For project-wide Codex policy setup and local-folder installation, see the repository’s Codex instructions. For Claude Code scopes and validation, see the Claude Code instructions.

Option 2

Desktop-client installation

Add the marketplace through the application UI, then install OpenStudio AI. The equivalent steps are arranged side by side so you can follow the client you use.

Claude Code Desktop

Open the Plugins directory to add and install OpenStudio AI.

1

Add the marketplace

Choose Add marketplace, paste the repository URL, and select the suggested Use option.

https://github.com/pnnl/openstudio-ai-plugins.git
2

Install OpenStudio AI

Select openstudio-ai-local, then click + beside OpenStudio AI.

3

Run setup

Start a session for your project, type /setup-openstudio-ai, and select the setup skill.

Codex Desktop

Open Customize, then Plugins, to add and install OpenStudio AI.

1

Add the marketplace

Open Customize → Plugins, choose Add → Add plugin marketplace, paste the source, and select Add marketplace.

https://github.com/pnnl/openstudio-ai-plugins.git
2

Install OpenStudio AI

Under Personal → OpenStudio AI Local, click + beside OpenStudio AI.

3

Run setup in a task

Open a project task, type /setup-openstudio-ai, and choose OpenStudio AI: Setup OpenStudio AI.

The setup skill checks your local runtime and explains any missing requirements before you begin modeling.

Optional terminal step

Add OpenStudio-MCP

OpenStudio AI works with the plugin alone. Add OpenStudio-MCP when your workflow needs its local, containerized OpenStudio capabilities.

Docker-based provider

Prepare the local OpenStudio-MCP runtime

Install and start Docker Desktop first, then download the OpenStudio-MCP image. The provider setup guide covers the final client configuration and required Docker mounts.

macOS with Homebrew

Install Docker Desktop and confirm that it is running.

brew install --cask docker
open -a Docker
docker version

Windows PowerShell

Install Docker Desktop and confirm that Docker is available.

winget install -e --id Docker.DockerDesktop
docker version

Pull and connect

Download the image, then configure it for your chosen client.

docker pull nrel/openstudio-mcp:devOpenStudio-MCP setup guide ↗
